# Front Range Watch

Where new development in El Paso County, Colorado meets wildfire risk. Live app: https://carlos-barrera-gis.github.io/front-range-watch/

- Imagery swipe: Esri World Imagery Wayback, 198 dates since 2014
- Burn scars: NIFC Interagency Fire Perimeter History
- Planning projects and WUI: El Paso County public layers, analyzed once and cached in front_range_watch_projects.geojson (Nov 6, 2026). The app does not query county servers.
- Live fire detections: NASA VIIRS via Esri Living Atlas

Built by Carlos Barrera. Independent project; not an official county product.
